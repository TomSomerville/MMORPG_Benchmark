Abbreviations: Cu/Bz/Fe/St/Sm Bar = Copper/Bronze/Iron/Steel/Starmetal Bar; LL/ML/HL = Light/Medium/Heavy Leather; SP = spell power; AP = attack power.

## 8. Post-launch reserve

Artisan (300) recipes, plate armor (Blacksmithing at 40), specialisations (armorsmith/weaponsmith, gnomish-style gadget schools, elixir/potion master), profession quests, crafted epics using raid materials (*Vault Pearl*, *Hollow Shard Fragment* — already defined as raid drops with no launch use beyond one legendary-quest reserve).
